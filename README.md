## 2. このアイデアはどこから生まれたか

### 2-1. きっかけとなった体験・感情

#### 2-1-1. 他者との違いを理解できなかった経験
これまで、人と関わる中で、自分ならこう判断する、自分ならこう感じる・こう行動するはずという感覚を相手にも当てはめてしまい、相手がそれと異なる言動を取ったときに、理由を理解できず戸惑うことが何度もありました。
私は元々、相手の言葉をそのまま受け取るだけでなく、その言葉の裏にある意図まで考えることが多いタイプです。
例えば、移動中に相手から「あとどのくらいで着くかな」と言われたとき、「到着時間を調べてほしい」という意味かも？と受け取り、気になるなら自分で調べたらいいのに…と内心で負担を感じながら調べたことがあります。
しかし、蓋を開けると相手には何かを頼む意図はなく、ただそのとき思ったことを口にしただけでした。
反対に、自分が相手に何かをしてほしいときにも、直接お願いするのではなく、相手が言葉の意図を読み取ってくれることを無意識に当たり前として期待してしまうことがありました。
しかし、相手が自分と同じように行間を読んだり言動の意図を想像して対応するとは限らないため、意図が伝わらず、「なぜ分かってくれないのだろう」と感じることもありました。

このようなすれ違いが起きると、私は相手の一つの言動から、その背景にある考え方や人間性まで推測し、「配慮がないのではないか」「なぜこのような判断をするのだろう」と責める気持ちを持ってしまうことがありました。
その一方で、相手から見れば、何気なく発した一言に対して私がなぜそこまで反応しているのか理解できず、お互いに納得できないまま気持ちだけがすれ違ってしまうという経験がありました。

#### 2-1-2. 16タイプ・心理機能との出会い
自分と他人との「普通」の違いや、人とのすれ違いについて考えたり、いろいろ調べていく中で、16タイプや心理機能に関する情報に触れました。
そこで、人によって情報の受け取り方や判断するときに重視するものに、それぞれ異なる傾向があることを知りました。

それまでは、相手が自分の当たり前や普通とは異なる言動を取った時、自分の中の基準と照らし合わせてしまい、「なぜそのように考えるのか分からない」「配慮が足りないのではないか」などと感じていました。
しかし心理機能について知ることで、自分にとって自然な受け取り方や判断基準が、相手にとっても同じとは限らないと考えられるようになりました。

例えば、何気なく発せられた一言に対して、そのままの意味を受け取る人もいれば、言葉の裏にある意図や、その後に求められている行動まで考える人もいると思います。
どちらかが正しい、どちらかが間違っているという話ではなく、同じ出来事でも注目する部分や連想する範囲が異なるため、それが要因で生まれる認識のずれがあるのだなと分かりました。

この考え方を知ってから、相手の言動に共感できない場合でも、「この人は何を基準に判断したのだろう」「自分とは異なる何を大切にしているのだろう」と考えられるようになりました。
相手を完全には理解できなくても、その背景を想像することで理解を示しやすくなり、自分と他者との違いに寛容になれたり、相手を責める気持ちが和らぐ経験が増えました。

また、自分自身についても、どのような場面で言葉の裏を読もうとしやすいのか、何に違和感や負担を感じやすいのかを振り返るきっかけになりました。
16タイプや心理機能は、相性の良し悪しを決めたり、人を型にはめたりするものではなく、自分と他者の違いを理解するための一つの手がかりとして活用できるのではないかと感じるようになりました。

この経験から、16タイプを単に診断結果として表示するだけでなく、それぞれのタイプが物事をどのように捉えやすい傾向にあり、どのようなことを負担に感じやすいのかなど、身近な言葉で知れる仕組みがあればよいのではないかと考えるようになりました。
自分と同じタイプの言葉には「分かる」と共感でき、異なるタイプの言葉には「こういう人もいるのかも」「あの人にもこう見えているのかもしれない」と、別の視点を知るきっかけになるような体験を作りたいと考えています。

#### 2-1-3. SELFを利用して支えられた経験
2017年ごろ、会話を通してユーザーの性格や生活の傾向を分析し、それに合わせた言葉をかけてくれる「SELF」というスマートフォンアプリを利用していました。
アプリ内のキャラクターと会話を重ねる中で、自分の性格や考え方を言葉にしてもらったり、そのときの気持ちに寄り添う言葉をかけてもらったりすることがありました。「自分はこのような傾向を持っているのかもしれない」と立ち止まって考える時間や、自分のことを理解してもらえたように感じられる体験に支えられていました。
当時、画面を何枚もスクリーンショットして、今もカメラロールに残っていることからも、その言葉や体験が自分の心に残っていたのだと思います。
この経験を通して、忙しい日常から少し離れ、キャラクターとのやり取りをきっかけに自分と向き合う時間そのものに価値があると感じるようになりました。

#### 2-1-4. ChatGPTを使った内省と感じた課題
現在は、ChatGPTとの対話も自己理解や他者理解を深めるために活用しています。
自分の中にあるモヤモヤを言葉にし、「なぜその言葉に傷ついたのか」「本当は何を求めていたのか」「相手にはどのように見えていた可能性があるのか」など、対話を重ねることで、最初は言葉にできなかった感情や考えが少しずつ整理されて散らかった脳内がスッキリ整頓されていく感覚を得る体験がありました。

また、自分だけでは思いつかなかった見方を提示してもらうことで、ひとつの出来事を別の角度から捉え直したり、自分と相手の間にある認識のずれの可能性に気づけたりすることもありました。
対話を通してバラバラだった情報がつながり、自分の感情や行動に納得できたときには、気持ちが軽くなり、次はどのように向き合えばよいかを前向きに考えられるようになりました。

一方で、このような使い方をするためには、ユーザー自身が考えたいテーマを決め、状況や感情を文章にして質問する必要があります。
もともと内省する習慣がない人にとっては、何をどのように尋ねればよいか分からず、言語化が難しかったり、自由入力そのものが負担になる可能性があります。
また、自己理解のためにAIと対話するという使い方自体が、選択肢として思い浮かばない人もいると考えました。

そこで、自由に質問を考えなくても、キャラクターの言葉や用意された選択肢を入口として、自分の感情や考えを少しずつ振り返れる仕組みがあれば、自己分析に慣れていない人でも自己理解を始めやすくなるのではないかと考えました。

### 2-2. なぜそれが「気になった」のか

私は、人の言動をそのまま受け取るだけでなく、「なぜそのように考えたのか」「その言葉や行動の背景には何があるのか」まで考え、筋道を立てて理解したい傾向があります。
そのため、自分とは異なる判断や行動の理由が分からないまま残ると、強い違和感やモヤモヤを抱きやすいのだと思います。

一方で、相手の考えを自分の基準だけで推測すると、想像力が暴走し、実際にはなかった意図まで読み取り、「こう思っての発言に違いない」など決めつけるような思考に至ったり、誤解やすれ違いを生んでしまうことがあります。
相手を理解できないことが、そのまま「配慮がない」「自分とは合わない」といった否定につながってしまうことにも抵抗がありました。

私は、すべての考えに共感することよりも、自分と異なる考え方が生まれた背景を知り、理解を示そうとする姿勢を大切にしたいと考えています。
自分の中の「普通」が誰にとっても同じではないと知ったり、頭では分かっていても改めて認識することで、他者に寛容になり、同時に自分自身の感じ方についても理解を深めたいという思いが、このテーマを気にし続けてきた理由だと思います。

### 10-3.キャッチアップ不足の懸念

キャッチアップ不足の段階では以下の懸念点があります。
1. **完成までのハードルが高い**
使用する言語やフレームワークが異なるため、キャッチアップにかかる時間は個人差があるものの、一定の時間を要することが予想されます。
2. **Issueの見積もりが難しい**
「どこまで理解していて、何が分からないのか」「調査にかかる時間」などが不明瞭な場合、開発期間内に完了することが難しくなってしまいます。

例えば、最近注目されているReactやNextについて。
Reactについては**本リリース後に組み込む方向で検討**するのが良いかと考えています。
その後、React単体のキャッチアップを行い、アプリに組み込む技術的な検証をした上で、組み込むかどうかを判断する形が理想かもしれません。
